A practical introduction to **Python-based image processing** for **ARTI 403 – Image Processing**.

This lab demonstrates how digital images can be loaded, visualized, represented as NumPy arrays, and manipulated using fundamental image-processing operations.

---

## 📌 Lab Overview

The main objective of this lab is to understand how digital images are represented and manipulated using Python.

The project focuses on:

- Loading images using **OpenCV**
- Loading images using **PIL (Pillow)**
- Visualizing images using **Matplotlib**
- Representing images as **NumPy arrays**
- Inspecting image dimensions and pixel values
- Performing basic image-processing operations using NumPy

---

## 🎯 Learning Objectives

By completing this lab, I practiced:

1. Understanding how digital images are represented in a computer.
2. Reading images using different Python libraries.
3. Displaying images using Matplotlib.
4. Understanding image dimensions and pixel matrices.
5. Converting images into NumPy arrays.
6. Performing basic pixel-level image transformations.
